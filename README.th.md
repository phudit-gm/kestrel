# Kestrel (ภาษาไทย)

มอด Fabric ฝั่ง client ช่วยเล็ง ถือธนู หน้าไม้ หรือตรีศูล แล้วมอดจะแสดงเส้นวิถี กรอบเป้าที่ยิงถึง
และตำแหน่งที่เป้าที่เคลื่อนที่จะอยู่ตอนลูกธนูไปถึง มีโหมด B ที่หมุนกล้องไปที่จุดเล็งให้เอง

ไม่ต้องลงอะไรที่ server และ server ปิดฟีเจอร์ได้เอง (ดูหัวข้อ "สำหรับเจ้าของ server")

## ติดตั้ง
1. ลง Fabric Loader + Fabric API ให้ตรงเวอร์ชัน Minecraft (1.21.11, 26.2 หรือ 26.3)
2. ใส่ไฟล์ `kestrel-<เวอร์ชัน>.jar` ในโฟลเดอร์ `mods`
3. ถ้าต้องการหน้าตั้งค่าในเกม ให้ลง Cloth Config และ Mod Menu เพิ่ม
4. ถือธนูแล้วโก่งสาย กด **R** สลับโหมด A / B

## โหมด A และ B
- **A (ดูตัวอย่าง):** คุณเล็งเอง มอดแสดงเส้นวิถีและจุดตก
- **B (เล็งอัตโนมัติ):** กล้องหมุนไปที่จุดเล็งเอง ขยับเมาส์เพื่อสลับเป้า
  เล็งหัวเมื่อเป้ายืนบนพื้นและหัวไม่ติดบล็อก ถ้าเป้ากำลังกระโดด ตก ว่ายน้ำ หรือหัวถูกบังจะเล็งกลางตัวแทน

## คำเตือนเรื่องโหมด B
โหมด B คือการช่วยเล็ง หลาย server โดยเฉพาะ PvP ไม่อนุญาต มอดจะเตือนในแชทครั้งแรกที่ใช้บน server
**ผู้เล่นต้องรับผิดชอบการทำตามกฎของ server เอง** ปิดโหมด B ได้ที่ ตั้งค่า > Mode B

## เลือกว่าจะเล็งใคร
ค่าเริ่มต้น: โหมด A เล็งมอนสเตอร์กับผู้เล่น โหมด B เล็งแค่มอนสเตอร์ ปิดสัตว์ ชาวบ้านและอื่น ๆ
เปลี่ยนได้ที่ตั้งค่า > Targeting และ Mode B แยกกันสองโหมด และเพิ่มรายการ ID ที่ให้ล็อกเสมอหรือห้ามล็อกได้

## สำหรับเจ้าของ server
สร้าง team ชื่อพิเศษ ฟีเจอร์ที่ตรงกันจะปิดให้ผู้เล่นทุกคนที่ใช้ Kestrel ไม่ต้องลงมอดที่ server
วางโฟลเดอร์ `datapacks/kestrel_rules` ใน `<world>/datapacks` แล้ว `/reload` จากนั้น:

```
/function kestrel_rules:modeb/off          ปิดโหมด B
/function kestrel_rules:predict/off        ปิดเงาและการนำเป้า (โหมด B ปิดด้วย)
/function kestrel_rules:lock/off           ปิดกรอบเป้าและการล็อก
/function kestrel_rules:path/off           ปิดเส้นวิถี
/function kestrel_rules:players/off        ห้ามล็อกผู้เล่น
/function kestrel_rules:all/off            ปิดมอดทั้งหมด
/function kestrel_rules:preset/pvp_safe    ชุดสำหรับ PvP
```
ทุกกฎมี `/on` คู่กัน **นี่เป็นคำขอที่มอดทำตาม ไม่ใช่ระบบกันโกง** คนที่แก้มอดไม่ได้รับผลกระทบ
